# 沦敦故事回顾（Fallen London Chronicle）

自动把你在沦敦里**每一次选择**的完整文字保存下来：故事开头、你选的选项、结果正文、属性/物品变化，一个字都不丢。可以搜索、星标、写笔记，还能导出成网页、Markdown、TXT 或完整备份。

## 为什么不会丢字

游戏自带的日志（Journal）每条只保存标题、游戏内日期、地点，以及保存时填写的那段文字，不会保留完整的结果正文。这个工具换了一种方式：

1. **直接保存服务器发来的原文**：你每做一次选择，游戏都会从服务器收到一整份数据。工具会把这份数据原封不动地存下来，再从里面整理出标题和正文。就算哪天游戏改版、整理时漏了内容，原始数据也还在（每条记录的“原始数据”按钮）。
2. **同时保存“页面显示文本”**：如果你用了汉化插件，工具还会等页面翻译完成后，把你**实际看到的文字**也存一份。每条记录上可以在“游戏原文 / 页面显示文本”之间切换。

工具只“旁听”，不改动、也不额外发送任何请求，不影响游戏本身。

## 安装方式一：Chrome 插件（推荐）

不需要 Tampermonkey。适用于 Chrome、Edge 等 Chromium 内核浏览器（Chrome 111 及以上）。

1. 下载 [`fallen-london-chronicle-chrome.zip`](https://github.com/Dobo233/fallen-london-chronicle/raw/main/dist/fallen-london-chronicle-chrome.zip)，解压到一个**固定的文件夹**（以后不要删除或移动它，浏览器会一直从这里加载插件）。
2. 在地址栏打开 `chrome://extensions`（Edge 是 `edge://extensions`），打开右上角的 **开发者模式**。
3. 点 **加载已解压的扩展程序**，选择上面那个文件夹（里面直接有 `manifest.json` 的那一层）。
4. 建议把插件“固定”到工具栏（点拼图图标 → 图钉）。
5. 刷新 fallenlondon.com，右下角出现 **📜 回顾** 按钮就说明装好了。

> 如果你之前装过 Tampermonkey 版本：请在 Tampermonkey 里**停用**“沦敦故事回顾”脚本，避免两份同时运行。两个版本的记录存在同一个地方，切换后原有记录都还在。

### 插件工具栏按钮

在沦敦页面上点插件图标，可以：
- **打开回顾面板**
- **导入游戏日志**：读取你在游戏里“保存到日志”的全部条目（逐页读取，只读不改），作为“游戏日志”类记录加入回顾。重复导入会自动去重，并保留你给这些条目加的星标和笔记。
- **在阅读器中查看全部记录**：把记录复制到插件自带的阅读器，在新标签页里全屏阅读，不用开着游戏。
- **导出完整备份 JSON**

不在沦敦页面时，也可以点“打开离线阅读器”，打开插件自带的阅读器，或用它打开备份文件。

## 安装方式二：Tampermonkey 脚本

1. 在浏览器里装一个用户脚本管理器：**Tampermonkey**（Chrome / Edge / Firefox 都有）或 **Violentmonkey**。
   - Chrome / Edge 用户：装好后，在扩展的“详细信息”里打开 **“允许运行用户脚本”**（新版 Chrome 需要这一步，或者打开扩展管理页右上角的“开发者模式”）。
2. 打开 [安装链接](https://raw.githubusercontent.com/Dobo233/fallen-london-chronicle/main/dist/fallen-london-chronicle.user.js)，Tampermonkey 会弹出安装页，点“安装”。以后有新版本时，Tampermonkey 会自动更新。
3. 刷新 fallenlondon.com。右下角出现 **📜 回顾** 按钮就说明装好了。

## 其他浏览器

- **Edge、Brave、Opera、Vivaldi** 等 Chromium 内核浏览器：和 Chrome 完全一样，用“安装方式一”。只是扩展管理页的地址不同：`edge://extensions`、`brave://extensions`、`opera://extensions`、`vivaldi:extensions`。
- **Firefox（电脑版 128 及以上）**：
  - **推荐**：用“安装方式二”，在 Firefox 里装 Tampermonkey 或 Violentmonkey，再打开脚本安装链接。会自动更新，重启浏览器也不会消失。
  - **也可以用插件版**：下载 [`fallen-london-chronicle-firefox.zip`](https://github.com/Dobo233/fallen-london-chronicle/raw/main/dist/fallen-london-chronicle-firefox.zip)，在地址栏打开 `about:debugging#/runtime/this-firefox`，点 **临时载入附加组件**，选这个 zip。注意：Firefox 只允许长期安装经过 Mozilla 签名的插件，**临时载入的插件在关闭 Firefox 后会被移除**，每次都要重新载入。签名版发布后会在这里更新链接。
  - 如果装好后游戏页面上没有出现按钮：打开 `about:addons` → 沦敦故事回顾 → **权限**，确认允许访问 fallenlondon.com，然后刷新游戏页面。
- 不管用哪个浏览器，记录都只保存在**那个浏览器**里。换浏览器前，先在旧浏览器里“导出 → 完整备份 JSON”，再在新浏览器的回顾面板里导入。

## 在手机上使用

**手机版 Chrome（安卓和 iPhone 都一样）不支持安装任何扩展或脚本**，这是 Chrome 本身的限制，没有办法绕过。要在手机上记录，需要换一个支持扩展的浏览器：

**安卓 · 推荐做法：Firefox + Tampermonkey**

1. 在应用商店安装 **Firefox**。
2. 打开 Firefox → 右上角菜单（⋮）→ **附加组件** → 找到 **Tampermonkey**（或 Violentmonkey）→ 添加。
3. 在 Firefox 里打开 [脚本安装链接](https://raw.githubusercontent.com/Dobo233/fallen-london-chronicle/main/dist/fallen-london-chronicle.user.js)，点“安装”。
4. 在 Firefox 里登录 fallenlondon.com，右下角出现 **📜 回顾** 就装好了。

**安卓 · 其他可选浏览器（未经测试，自行判断）**

- **Edge 安卓版**：正式版只能装微软挑选的少数扩展，装不了这个插件；Edge Canary 测试版在开发者选项里可以加载 `.crx` 文件，比较折腾。
- **Quetta** 等第三方浏览器：可以直接安装 Chrome 插件的 zip 或脚本，但它们来自小团队，你的游戏登录状态会经过它们，请自己评估是否信任。
- **Yandex、Vivaldi**：只能从 Chrome 应用商店安装扩展，而本插件没有上架商店。
- Kiwi 浏览器已于 2025 年停止开发，不再推荐。

**iPhone / iPad**：iOS 上所有浏览器都是 Safari 内核。可以试试 App Store 里免费的 **Userscripts** Safari 扩展，用它加载上面的脚本（未测试）。

**手机上按钮挡住游戏怎么办**：

- 按住右下角的按钮（或左边的 ⋮⋮ 把手）**拖到任意位置**，松手后位置会记住，下次打开还在那里。轻点按钮仍然是原来的功能，拖动不会误触。
- 在“设置”里勾选 **右下角按钮只显示图标**，按钮会缩小一半。
- 拖乱了可以在“设置”里点 **按钮放回右下角**。

## 使用

- 正常玩游戏就好，每次选择后按钮会闪一下，并显示本次新增条数。
- 点 **📜 回顾**（或按 **Alt+J**）打开回顾面板，按 **Esc** 关闭。
- **沦敦风格显示**（默认）：按登录后游戏页面实测的样式排版，字体、尺寸、纸张纹理、阴影都和游戏一致：
  - 故事开头：和游戏的故事框相同；
  - 你所选的选项：缩进的选项卡片，带小卡片图标，右下角有青色“已选择”按钮；
  - 结果：和游戏结果页相同；
  - 变化列表：带 36px 物品/属性图标。

  工具栏里可以切换成“紧凑”样式。图标和纹理直接从游戏服务器加载，所以离线时不显示，文字不受影响。
- **搜索**：会搜全部文字，包括故事、选项、结果、变化、页面显示文本和你的笔记。
- **按故事筛选**：在下拉框里选一个故事，再把排序改成“旧 → 新”，就能按先后顺序把整条故事线读一遍。
- 每条记录上的按钮：
  - ☆ 星标
  - 笔记（输入后点别处自动保存）
  - 复制（把这一条的全部文字复制到剪贴板）
  - 原始数据（查看服务器原文）
  - 删除
- **开关记录**：右下角“📜 回顾”旁边就是记录开关，点一下即可切换：红点“● 记录中”表示正在记录，灰色“❚❚ 已暂停”表示已暂停（快捷键 **Alt+K**）。面板顶部按钮、插件工具栏弹窗、“设置”里也能切换，几处始终同步，设置会一直保留（刷新页面也不变）。暂停时不会记录任何选择，也不会标记“已存入日志”。暂停期间插件仍会留意你当前所在的故事，所以恢复后下一次选择照样能带上完整的故事和选项。导入日志、浏览和导出在暂停时都能正常使用。
- **同一故事的多次选择合并显示**：在同一个故事里先后选了不同选项（例如先选 A，回来再选 B），回顾时会合并成一张故事卡：故事开头和选项只显示一次，选过的选项标着“第 1 次选择”“第 2 次选择”，下面按顺序列出每次选择的结果和变化。每次选择仍有自己的星标、笔记、删除按钮；网页、Markdown、TXT 导出也按同样方式合并。（相邻的同一故事记录才会合并；中间去过别的故事则分开显示。用“按故事筛选”可以把同一故事的全部记录排在一起。）
- **翻译（原文 / 译文 / 对照）**：开着 Chrome 自带的“翻译此页”（或沉浸式翻译等）玩游戏时，插件会按游戏页面的结构**逐项**保存译文：故事标题和开头、每个选项（含挑战说明）、结果标题和正文、每一条变化，都和原文一一对应。Chrome 翻译是慢慢替换文字的，插件会一直跟着更新，直到你离开那一页。游戏页面上变化消息的顺序和服务器发来的顺序不一定一样，插件会按每条消息旁边的图标把译文配到对应的原文上（1.4.3 之前存下的译文，会在显示时按数字和英文名重新配对）。回顾时用面板顶部的“原文 / 译文 / 对照”切换显示；导出的网页、Markdown、TXT 也按这个设置来。旧版本抓到的“页面显示文本”常常对不上（抓到侧边栏或下一页），这些旧记录仍可在“旧版页面文本”里看到，新记录不再使用它。
- **随进度变化的文字**：每次选择都会单独保存当时的故事开头、全部选项和结果原文，不会互相覆盖。同一个选项在不同进度下得到不同的结果，会分开显示；故事开头或某个已有选项的文字变了，故事卡里会出现“故事页的文字变了 · 从第 n 次选择起”，下面显示新版本的开头和选项（新解锁的选项不算变化）。导出也按这个结构。
- **相同的结果自动合并**：在同一个故事里反复选同一个选项、得到同一个结果时（比如梦境里的重复动作），只显示一次结果，标题标着“第 1、2、11、13 次 ×4（结果相同）”；每次不同的变化（例如“上限变为 1”和“没有变化”）会分别列在下面，每次仍可单独加星标、写笔记、删除。
- **📖 日志本（分类与故事线）**：把属于同一条大故事的事件整理成一本本日志。
  - **收入日志本**：每张故事卡片上都有“📖 日志本”按钮，勾选要收入哪几本，或者新建一本。一个故事可以同时属于几本日志。卡片上会标出它所在的日志本。
  - **阅读日志本**：点面板顶部的“📖 日志本”进入日志本视图。左边是你的日志本，右边按章节顺序显示这本日志里的故事；每一章就是一个故事，下面是你在这个故事里的全部选择和结果。
  - **自己调整**：可以改书名、写介绍，用 ↑ ↓ 调整章节顺序，或者把故事“移出”（只移出目录，记录不会被删除）。
  - **自动建议**：游戏里一个选择直接进入下一个故事时，插件会记下这两个故事是相连的。左边“自动发现的故事线”会列出这些连起来的故事，可以一键建成日志本；每本日志的末尾也会列出“可能属于这本日志的故事”，点一下就能加在相连的章节后面。“未归类的故事”列出还没收进任何日志本的故事。
  - **导出**：每本日志可以单独导出为网页、Markdown 或 TXT，按章节排版。日志本也会包含在完整备份 JSON 里，导入备份、插件阅读器、离线查看器里都能看到。
- **解锁条件**：游戏里选项（和故事）右下角的条件小图标也会记录并显示：鼠标悬停看原文说明，选项下面还会列出文字（✓ 已满足 / ✗ 未满足，未满足的标红）；导出的 TXT、Markdown 里也有。
- **故事下的全部选项**：每条记录都会保存当时故事下的**所有**选项（标题、描述、挑战说明如“你的 Watchful 有 100% 成功率”、未解锁选项的解锁条件），不只你选的那个。阅读时默认只显示你选的选项，点“显示当时其他 N 个选项”可以按原顺序展开其余选项（变淡显示，未解锁的为灰色）。
- **和游戏日志联动**：你在游戏里按“保存到日志”时，插件会把对应的完整记录标记为“已存入日志”；之后导入游戏日志时，这些条目会**直接合并进完整记录**（故事开头 + 全部选项 + 你的选择 + 结果 + 变化 + 日志标题与游戏内日期），不会另外生成一条只有标题的记录。勾选工具栏的“仅日志”就能只看这些。
- 面板顶部的 **游戏日志** 按钮也能导入游戏日志（脚本版和插件版都有）。导入的条目按游戏日志页的样子显示：标题、游戏内日期（地点）、正文，在“按故事筛选”里归在“游戏日志”下。
- 在安装本工具之前存入的日志条目，游戏只保存了标题和你留下的那段文字，导入后也只有这些；之后存入的条目都会带上完整的选项和后果。

## 导出与备份（重要）

记录保存在**这个浏览器的本地存储**里。清除浏览器数据、换浏览器或换电脑后，记录就看不到了。所以请**定期备份**：

- **导出 → 完整备份 JSON**：包含全部记录和原始数据，用来恢复或迁移。在新浏览器里点“导入”选这个文件即可，重复的记录会自动去重合并。
- **导出 → 网页 HTML**：同样是沦敦风格排版，适合阅读、打印、存档，双击就能打开，不需要任何工具。
- **Markdown / TXT**：方便放进笔记软件或继续编辑。
- 导出的范围就是当前筛选结果。比如先选好某个故事，再导出，得到的就是这条故事线的单独合集。

## 离线查看器

[`fallen-london-chronicle-viewer.html`](https://github.com/Dobo233/fallen-london-chronicle/raw/main/dist/fallen-london-chronicle-viewer.html)：下载后双击就能打开，不用登录游戏，也不用联网。把“完整备份 JSON”拖进去就能浏览和搜索，可以一次打开多个备份，会自动合并。

## 设置

在面板右上角的“设置”里可以调整：

- 保存页面显示文本：默认开启。
- 保存服务器原始响应：默认开启，建议保持开启，这是“不丢字”的保底。
- 调试模式：把所有接口数据都记一条。只在发现某类内容没被记录、需要排查时才开。

## 已知限制

- 已对照真实账号核对过：游戏使用的接口（`storylet/begin`、`storylet/choosebranch`）和返回数据的字段结构都与脚本的解析一致，挑战成败也按游戏消息判断。如果以后游戏改版，某次选择显示“没有解析出结果正文”，全文仍在原始数据里，把那条记录的原始数据发给我即可修正。
- 页面显示文本是“尽力而为”：它会挑结果出现后新增文字最多的区域。偶尔可能多带一点或少带一点周边文字，但游戏原文始终完整。
